## About the Project

This platform is part of the **MSP4GROWTH** project, aiming to facilitate sustainable marine spatial planning by leveraging advanced data preprocessing and optimization techniques. It uses Python scripts for data handling, processing, and spatial allocation, specifically tailored for marine environments.

### Built With
- Python
- Gurobi Optimizer
- PyAugmecon library
- QGIS (for visualizing results)

## Features

- **Data Preprocessing**: Prepares marine spatial data for analysis.
- **Function Library**: Contains reusable functions for spatial optimization.
- **Pipeline Execution**: Automates the execution of the full processing pipeline.
